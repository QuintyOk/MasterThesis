# Data files

The survey datasets are confidential and are not included in the public repository.

The scripts expect the following local files in this folder.

```text
Access & Mobility Survey Raw Data.xlsx
Access & Mobility Survey Clean Data.xlsx
Access & Mobility Survey Formatted Data.xlsx
Access & Mobility Survey Acceptability Raw Data.xlsx
Access & Mobility Survey Acceptability Clean Data.xlsx
Access & Mobility Survey Acceptability Formatted Data.xlsx
Ngene Design for Attribute Values.xlsx
```

The two raw files are the Qualtrics exports. The cleaning and formatting scripts create the clean and formatted files. The SCE formatting script also reads the final Ngene design.

Do not commit employee-level data, generated open-text documents, or files containing ResponseIds.
